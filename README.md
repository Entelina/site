# Entelina · 来希 官网源码

正在筹备中的 AI 共创社区官网。**41 个静态 HTML 页面**，无框架、无运行时依赖、不需要服务器。

仓库根目录的 HTML 就是线上页面本身——源码即成品，构建脚本只在改内容时用到。

> 这是「源码仓库」。社区的介绍入口在 [Entelina/Entelina](https://github.com/Entelina/Entelina)。

---

## 快速开始

打开 `index.html` 即可浏览全站。不需要安装任何东西，也不依赖在线脚本。

要修改内容，在仓库根目录运行：

```bash
node build.cjs
```

零依赖，无需 `npm install`。**Node 只在改内容时用到**，访问网站不需要它。

## 改哪里

| 想改的东西 | 文件 |
|---|---|
| 顶部导航、页脚、`<head>`（含 favicon 引用） | `build.cjs` |
| 首页与栏目页正文 | `pages-main.cjs` |
| 两款工具的页面 | `pages-tools.cjs` |
| 文章与期刊正文 | `content.cjs` |
| 交互（分组菜单、文章目录、站内搜索） | `app.js` |
| 样式 | `styles.css` |

运行 `node build.cjs` 会重写根目录的 41 个 HTML，并同步更新页面清单 `pages.json` 与搜索索引 `search-index.js`。

> **不要手改生成出来的 HTML** —— 下次构建会被覆盖。改内容一律从上面的源文件入手。

## 目录

```

```

## 标志与图标

主标志是八瓣放射展开的几何图形：八片尖端朝内的楔形 + 断开的墨绿外环 + 中心八角留白。全部为**真矢量 SVG**，不是位图包裹。

| 文件 | 用途 |
|---|---|
| `logo-ink.svg` | 彩色标志，浅色底使用（导航栏引用此文件） |
| `logo.svg` | 反白标志，深色底使用 |
| `logo-ink.png` / `logo.png` | 对应 1024px 透明底 PNG |
| `logo-avatar*.png/svg` | 头像（深墨绿底、纸白底、512px 标准尺寸） |

配色：深墨绿 `#173C34`、纸白 `#F6F6F2`、琥珀 `#B4761C`、陶土 `#9C4A16`。

`assets/` 下另有一套**为小尺寸单独优化过的图标变体**（`favicon.svg`、`favicon-32.png`、`apple-touch-icon.png`，根目录另有 `favicon.ico`）。它与主标志几何同源，但去掉了在 16–32px 下等于不存在的低对比度内八角环，并把套版缝加宽，保证小尺寸仍能看出「八瓣轮盘」的结构。

> ⚠️ **换图标后必须改 URL。** favicon 的缓存比页面顽固得多，普通刷新与强制刷新都可能不更新，所以引用里带了版本号 `?v=3`。换图标时把 `build.cjs` 中 `<head>` 里的 `?v=` 数字加一，再重新构建。

标志与图标由一组 Python 脚本生成（矢量参数、PNG 光栅化、小尺寸图标各一个，未纳入本仓库）。改配色或比例请改脚本重新生成，**不要手改 SVG**。

## 部署

纯静态站点，本仓库根目录即产物目录——任意静态托管都能直接发布，仓库内没有任何服务端代码、数据库或第三方脚本。

线上托管在 EdgeOne Pages（腾讯云）：构建命令留空，输出目录为 `/`，推送默认分支即自动部署。

## 范围

这是真实可用、也真实受限的官网，这里如实写明边界：

**可以用**

- 两款**浏览器内运行的本地工具**：Brief 结构化创作简报、Index Markdown 阅读结构

**还没做**

- 工具**不调用 AI 模型**，也不上传你的输入
- 没有账号、投稿接收、云端保存、数据库或付费功能
- 共创提案只能本地生成并下载，**不会自动提交**
- 第 000 期为品牌习作样刊，不代表真实的社区评选
- 社区仍在筹备中：投稿、账号、讨论入口、社区评选与正式期刊**均未开放**，也没有承诺开放时间
- 站内不出现社区人数、历史成绩或合作方

参考素材只用于研究，未复制任何第三方品牌资产到成品。
