Brief 与 Index 使用说明

输入格式、输出内容，以及工具的实际边界。

Entelina 编辑与开发记录2026.09.13初版
本页内容Brief：整理创作简报Index：检查文档结构导出与复制数据与限制

Brief：整理创作简报

填写项目名称、目标与受众、交付形式和约束。点击“生成简报”后，工具按固定结构组织这些字段，并附上用于复核的检查项。它不会改写你的判断，也不会调用 AI 模型补全信息。

可以直接复制结果，也可以下载 Markdown 文件。生成后继续修改字段，需要再次点击生成才能更新输出；页面刷新后输入不会保留。

Index：检查文档结构

将 Markdown 文本粘贴到输入区，点击“分析结构”。工具识别以一至六个 # 加空格开头的标题，并忽略反引号或波浪线代码围栏内的内容。输出保留标题顺序与原始行号。

当标题层级从一级直接跳到三级时，工具会给出提示。没有标题的文档会显示空结果说明。当前不识别下划线式标题、HTML 标题或文档语义，也不生成摘要。

导出与复制

下载内容是 UTF-8 编码的 Markdown 文本，可以使用普通文本编辑器打开。复制依赖浏览器剪贴板权限；如果浏览器禁止复制，可以使用下载按钮。

数据与限制

两款工具都在浏览器内处理文本，不会把输入发送到远端。Brief 的长文本字段最多 2,000 个字符，Index 最多 100,000 个字符。刷新页面会清空工作内容，请先导出需要保留的结果。
