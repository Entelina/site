第一次来到 Entelina

根据你想完成的事情，选择一条清楚的起点。

Entelina 编辑与开发记录2026.09.13初版
本页内容先选择一个任务用资源解决具体问题准备你的第一次贡献了解当前边界

先选择一个任务

如果你需要组织创作需求，可以从 Brief 开始；如果你正在整理长文档，可以使用 Index 查看标题结构。两款工具都不需要账号，也不需要连接模型。

如果你还没有明确任务，可以先阅读作品样刊。作品详情除了展示结果，也记录主题、工具和取舍，帮助你理解一个想法如何变成可分享的成果。

用资源解决具体问题

  • 文档说明如何使用工具，以及如何准备发布材料。
  • 用例从一项任务出发，展示工具在流程中的位置。
  • 实用手册整理可重复的方法，例如提示设计和作品复盘。
  • 开发者案例与博客记录实现过程及工程判断。

准备你的第一次贡献

选择产品共创、作品展示或资源文章中的一种，写下问题、现有成果与需要的帮助。对素材、工具和协作者进行清楚署名。提案页面可将这些信息整理为 Markdown 文件。

正式投稿和讨论服务尚未开放。目前生成的提案只供你下载保存，不会自动发送给任何人。

了解当前边界

这是官网与本地工具的初版。作品区提供第 000 期样刊；没有预设的会员体系、模型 API、云端存储或付费计划。工具页面会具体说明能做什么以及不能做什么。
